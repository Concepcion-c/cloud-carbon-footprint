# TRACE — Hackathon Workspace

This is the **private** working copy for the Cloud Carbon Footprint / AI emissions
hackathon project. It contains both the CCF codebase (seeded from the public fork)
and all private materials — notes, PRDs, and research — under [`hackathon/`](./hackathon/).

The finished, notes-stripped result gets published to the **public fork** when ready.
See [`hackathon/README.md`](./hackathon/README.md) for the workspace overview and the
publish workflow.

## Remotes

| Remote     | Repo                                              | Purpose                         |
|------------|---------------------------------------------------|---------------------------------|
| `origin`   | `Concepcion-c/TRACE` (private)                     | Day-to-day work. Push freely.   |
| `public`   | `Concepcion-c/cloud-carbon-footprint` (public fork)| Publish target for final result.|
| `upstream` | `cloud-carbon-footprint/cloud-carbon-footprint`   | Pull upstream CCF updates.       |

> ⚠️ Never push the `hackathon/` folder to `public`. See the publish workflow before exposing anything.
